# Weatheria

A real-time weather application.

## Setup

Set API keys for [API Ninjas geocoding](https://api-ninjas.com/api/geocoding) and [OpenWeather](https://openweathermap.org/api) in the environment:

```sh
export API_NINJAS_KEY="your-api-ninjas-key"
export OPENWEATHER_API_KEY="your-openweather-key"
npm start
```

The server listens on port `3000` by default. Set `PORT` to use another port.
